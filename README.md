## 👋 Hi, I'm Andrii

Software engineer from **Ukraine** 🇺🇦, on GitHub since 2012. Backend-leaning full-stack: production code in **C# / .NET** and **PHP / Laravel**, **TypeScript** on the front. These days most of my commits go into **Neovim plugins** written in Lua and **tooling for Claude Code**, and everything I build gets self-hosted on a VPS because renting a box beats renting a SaaS.

- 🔭 **Now building:** Neovim plugins and Claude Code plugins / skills
- 🖥️ **Daily drivers:** CachyOS (Arch, btw) · fish · Neovim · Zellij · Claude Code
- ☁️ **Homelab:** Docker + Dokploy on a VPS, DNS on Cloudflare, Telegram bots on long polling
- 💬 **Ask me about:** .NET clean architecture, Neovim plugin dev, userscripts, self-hosting
- 🌐 **Web:** [7kill.dev](https://7kill.dev)
